Each 16bit firmware ships with a single app built into it — the firmware and the app are the same binary. The web UI configures the app that is currently loaded, but it cannot switch apps. To use a different app (Sampler, Polysynth, FxRack, Elab, or Monosynth), you must flash the firmware built for that app. See [Updating the Firmware](/docs/16bit/updating-firmware).

![16bit UI](/images/docs/16bit-ui.png)

## Using the Firmware

1. First, plug 16bit into the Bread Modular base. Make sure you've powered it on.
2. Then connect 16bit to your computer (PC or Mac) using the USB-C socket on top. (You may also use any Android device, but you can't use any iOS device)
3. Visit the following web app: <https://breadmodular.com/ui/16bit>
4. Click the connect button and select your 16bit device (usually named as 16bit)
5. Now you can configure the loaded app. (You cannot switch apps from the UI — to change apps, flash the matching firmware.)
